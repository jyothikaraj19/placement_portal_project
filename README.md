# Placement Portal Project

A Django-based web application to manage campus placements efficiently for students, recruiters, and placement officers.

### 🚀 Features
- **Student Module:** Register, update profile, apply for jobs, track application status
- **Recruiter Module:** Post job openings, view applicants, shortlist candidates
- **Admin/TPO Module:** Manage students, companies, and placement drives
- **Authentication:** Secure login & registration system

### 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** SQLite3 (Django default)
- **Tools:** Git & GitHub

### 📂 Project Structure
- `accounts` - User authentication & profiles
- `jobs` - Job posting & applications
- `placements` - Placement drive management
- `placement_portal` - Main project settings
